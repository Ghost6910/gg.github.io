เสริมติว: Router กับ Switch

Router อ่าน IP header เพื่อเลือก next hop และสร้าง frame ใหม่สำหรับลิงก์ขาออก ส่วน Ethernet switch ใช้ destination MAC และตาราง MAC ภายในโดเมนชั้น 2 ทั่วไป MAC ต้นทาง/ปลายทางจึงเปลี่ยนตามแต่ละลิงก์ที่ผ่าน router ขณะที่ IP ต้นทาง/ปลายทางคงเดิมในกรณีพื้นฐานที่ไม่มี NAT หรือ tunnel

ลองตอบ: TCP/IP 4 ชั้นกับ 5 ชั้นอันไหนถูก

เฉลยและเหตุผล: ทั้งสองเป็นวิธีจัดกลุ่มที่ใช้สอนได้ ต้องบอกชื่อแบบจำลองและการรวมชั้นให้ตรงกัน 5 ชั้นแยก Physical ออกจาก Link ส่วน 4 ชั้นรวมเป็น Network access

ลองตอบ: Frame ต่างจาก packet อย่างไร

เฉลยและเหตุผล: Frame เป็นหน่วยข้อมูลชั้นลิงก์ ส่วน IP packet/datagram เป็นหน่วยชั้นเครือข่าย IP packet ถูกบรรจุอยู่ภายใน frame และอาจถูกห่อด้วย frame ใหม่เมื่อข้าม router

จำให้ได้: จำหน้าที่แต่ละชั้นพร้อมหน่วยข้อมูลและที่อยู่ อย่าจำชื่อชั้นอย่างเดียว

2-4   TCP/IP PROTOCOL SUITE
The layers in the TCP/IP protocol suite do not exactly match those in the OSI model. The original TCP/IP protocol suite was defined as having four layers: host-to-network, internet, transport, and application. However, when TCP/IP is compared to OSI, we can say that the TCP/IP protocol suite is made of five layers: physical, data link, network, transport, and application.
