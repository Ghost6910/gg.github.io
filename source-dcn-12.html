แปลและเรียบเรียงการใช้ช่องร่วมกัน

เมื่อหลายโหนดใช้ช่อง broadcast เดียวกัน ต้องมีกติกาเลือกผู้ส่ง MAC protocols แบ่งใหญ่ได้เป็น Random access, Controlled access และ Channelization เป้าหมายคือใช้ความจุได้ดี มีความเป็นธรรม และควบคุม overhead/ความหน่วงตามบริบท

Pure ALOHA ส่งทันทีเมื่อมีข้อมูล หากชนกันค่อยลองใหม่ ช่วงเสี่ยงชนยาว 2 เท่าของเวลาหนึ่ง frame ส่วน Slotted ALOHA กำหนดเริ่มส่งได้เฉพาะขอบ slot จึงลดช่วงเสี่ยง แต่ต้องประสานเวลา

ประสิทธิภาพ ALOHA

ในแบบจำลอง Poisson ที่ใช้สอน Pure ALOHA มี S=G e^(−2G) ค่าสูงสุด 1/(2e)≈0.184 ส่วน Slotted ALOHA มี S=G e^(−G) ค่าสูงสุด 1/e≈0.368 ตัวเลขนี้มีสมมติฐานเรื่องการมาถึง ขนาด frame และการชน ไม่ใช่ประสิทธิภาพ Wi-Fi จริง

CSMA ฟังก่อนส่ง แต่ยังชนได้เพราะ propagation delay: สองเครื่องที่อยู่ห่างอาจต่างคิดว่าช่องว่าง ก่อนคลื่นของอีกฝ่ายเดินทางถึง CSMA/CD ฟังการชนระหว่างส่ง แล้วหยุดและถอยรอ ส่วน CSMA/CA พยายามลดการชนด้วยการรอ/backoff และกลไกตอบรับตามระบบ

การควบคุมและแบ่งช่อง

Polling ให้ตัวควบคุมเรียกแต่ละโหนด ข้อเสียคือ overhead และตัวควบคุมเป็นจุดสำคัญ Token passing ส่งสิทธิ์เป็น token ข้อเสียคือดูแล token และเวลารอเมื่อวงใหญ่ วิธีเหล่านี้ไม่ได้ขจัดความหน่วงทุกชนิด

FDMA แบ่งความถี่, TDMA แบ่งเวลา และ CDMA ใช้ code แยกสัญญาณ การทำโจทย์ CDMA ต้องระบุการแทนบิตเป็น +1/−1 และสมบัติ code แล้วจึงคูณ/รวมและ correlate ไม่ควรใช้ XOR แทนทุกขั้นโดยไม่ดูนิยาม

เสริมติว Ethernet กับ Wi-Fi

Ethernet แบบ half-duplex ใช้ CSMA/CD แต่ Ethernet full-duplex ที่ต่อ switch point-to-point ไม่ต้องแก้การชนแบบ shared medium ส่วน Wi-Fi ใช้แนว CSMA/CA เพราะการตรวจการชนขณะส่งทำได้ยากและมีปัญหา hidden node

ลองตอบ: ฟังก่อนส่งแล้วทำไมยังชน

เฉลยและเหตุผล: เพราะสัญญาณเดินทางใช้เวลา แต่ละโหนดไม่ได้เห็นสถานะอีกฝั่งทันที จึงเริ่มส่งก่อนรู้ว่ามีอีกฝ่ายส่งแล้วได้

ลองตอบ: Wi-Fi เห็น SSID ต่างกันหมายความว่าไม่แย่งคลื่นหรือไม่

เฉลยและเหตุผล: ไม่ SSID เป็นชื่อเครือข่าย หากใช้ช่องทับซ้อนหรือใช้ช่องร่วมกันยังมีการรบกวนหรือแย่ง airtime ได้

จำให้ได้: Random access ไม่ได้แปลว่าไร้กติกา และอย่าใช้ CSMA/CD อธิบาย switched full-duplex ทุกกรณี

12-1   RANDOM ACCESS
In random access or contention methods, no station is superior to another station and none is assigned the control over another. No station permits, or does not permit, another station to send. At each instance, a station that has data to send uses a procedure defined by the protocol to make a decision on whether or not to send.

A pure ALOHA network transmits 200-bit frames on a shared channel of 200 kbps. What is the requirement to make this frame collision-free?
Example 12.2
Solution
Average frame transmission time Tfr is 200 bits/200 kbps or 1 ms. The vulnerable time is  2 × 1 ms = 2 ms. This means no station should send later than 1 ms before this station starts transmission and no station should start sending during the one 1-ms period that this station is sending.

บล็อกข้อความ 26 — A network using CSMA/CD has a bandwidth of 10 Mbps. If the maximum propagation time (including the delays in the devices

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
A network using CSMA/CD has a bandwidth of 10 Mbps. If the maximum propagation time (including the delays in the devices and ignoring the time needed to send a jamming signal, as we see later) is 25.6 μs, what is the minimum size of the frame?
Example 12.5
Solution
The frame transmission time is Tfr = 2 × Tp = 51.2 μs. This means, in the worst case, a station needs to transmit for a period of 51.2 μs to detect the collision. The minimum size of the frame is 10 Mbps × 51.2 μs = 512 bits or 64 bytes. This is actually the minimum size of the frame for Standard Ethernet.
