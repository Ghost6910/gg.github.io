แปลและเรียบเรียงวิธีสวิตช์

Circuit switching จัดสรรทรัพยากรให้การสื่อสารก่อนส่งข้อมูล โดยมีขั้นตั้งวงจร ส่ง และยุติ วงจรอาจเป็น slot หรือย่านความถี่ ไม่จำเป็นต้องเป็นสายโลหะเฉพาะที่เชื่อมตรงทั้งเส้น

Packet switching แบ่งข้อมูลเป็น packet แล้วใช้ทรัพยากรร่วมกันตามเวลาที่มีข้อมูล Datagram network ตัดสินเส้นทาง packet แต่ละตัว ส่วน Virtual-circuit network มีการตั้งสถานะเส้นทางและใช้ป้ายระบุวงจรเสมือนก่อนส่งข้อมูล

Message switching เก็บทั้งข้อความก่อนส่งต่อ ทำให้แต่ละโหนดต้องรองรับข้อความขนาดใหญ่ Packet switching แบ่งหน่วยให้เล็กลงจึงส่งแบบ pipeline ได้

Store-and-forward และเวลา

Store-and-forward ต้องรับ packet ทั้งก้อนก่อนเริ่มส่งก้อนนั้นบนลิงก์ถัดไป สมมติ packet L บิต ผ่าน N ลิงก์อัตรา R เท่ากันและไม่คิด propagation/queue/processing เวลา packet เดียวเท่ากับ NL/R

ตัวอย่าง L=8,000 บิต, R=1 Mb/s, 3 ลิงก์ ได้ 3×0.008=24 ms ถ้าส่ง P packet ต่อเนื่องบนเส้นที่อัตราเท่ากัน ในแบบจำลอง pipeline เวลาจบทั้งหมด=(N+P−1)L/R ไม่ใช่ NP L/R เพราะ packet คนละตัวอยู่คนละลิงก์พร้อมกันได้

8-1   CIRCUIT-SWITCHED NETWORKS
A circuit-switched network consists of a set of switches connected by physical links. A connection between two stations is a dedicated path made of one or more links. However, each connection uses only one dedicated channel on each link. Each link is normally divided into n channels by using FDM or TDM.

บล็อกข้อความ 37 — Design a three-stage, 200 × 200 switch (N = 200) with

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
Design a three-stage, 200 × 200 switch (N = 200) with 
k = 4 and n = 20.
Solution
In the first stage we have N/n or 10 crossbars, each of size 20 × 4. In the second stage, we have 4 crossbars, each of size 10 × 10. In the third stage, we have 10 crossbars, each of size 4 × 20. The total number of crosspoints is 2kN + k(N/n)2, or 2000 crosspoints. This is 5 percent of the number of crosspoints in a single-stage switch (200 × 200 = 40,000).

บล็อกข้อความ 39 — Redesign the previous three-stage, 200 × 200 switch, using the Clos criteria with a minimum number of crosspoints.

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
Redesign the previous three-stage, 200 × 200 switch, using the Clos criteria with a minimum number of crosspoints.
Solution
We let n = (200/2)1/2, or n = 10. We calculate k = 2n − 1 = 19. In the first stage, we have 200/10, or 20, crossbars, each with 10 × 19 crosspoints. In the second stage, we have 19 crossbars, each with 10 × 10 crosspoints. In the third stage, we have 20 crossbars each with 19 × 10 crosspoints. The total number of crosspoints is 20(10 × 19) + 19(10 × 10) + 20(19 ×10) = 9500.
