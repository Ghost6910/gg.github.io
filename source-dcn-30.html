แปลและเรียบเรียงคำพื้นฐาน

Plaintext คือข้อมูลก่อนเข้ารหัส Ciphertext คือข้อมูลหลังแปลงด้วยอัลกอริทึมและกุญแจ Encryption คือแปลงไป ส่วน Decryption คือแปลงกลับ ความปลอดภัยควรมาจากการปกป้องกุญแจและคุณสมบัติอัลกอริทึมตามแบบ ไม่ใช่หวังว่าไม่มีใครรู้วิธีที่ใช้

Symmetric cryptography ใช้กุญแจลับร่วมกันเพื่อเข้ารหัส/ถอดรหัสตามระบบ ส่วน Asymmetric cryptography ใช้คู่ public/private key ที่มีความสัมพันธ์ทางคณิตศาสตร์ ผู้รับเผย public key ได้แต่เก็บ private key เป็นความลับ บริบทของการใช้กุญแจขึ้นกับว่างานเข้ารหัสหรือเซ็น

Block, Stream และตัวอย่างเพื่อเรียน

Block cipher รับข้อมูลเป็น block ขนาดคงที่ตามอัลกอริทึม ต้องมี mode of operation เมื่อข้อความยาว ส่วน stream cipher สร้างลำดับกุญแจสำหรับรวมกับข้อมูล ต้องระวังการใช้ nonce/ลำดับซ้ำตามเงื่อนไขอัลกอริทึม

สไลด์มี substitution/transposition และอัลกอริทึมหลายยุคเพื่อสอนแนวคิด ไม่ใช่รายการเลือกใช้จริงทั้งหมด การที่คำนวณตัวอย่างถอดรหัสได้ไม่ได้ยืนยันความแข็งแรงเชิงความปลอดภัย

เลือก p=5,q=11 ได้ n=55 และ φ(n)=40 เลือก e=3 แล้ว d=27 เพราะ 3×27 mod 40=1 สำหรับ m=2 ได้ c=2³ mod 55=8 และถอด m=8²⁷ mod55=2 ตัวเลขเล็กนี้ใช้ให้เห็นความสัมพันธ์ ไม่ใช่กุญแจที่เหมาะกับใช้งาน

การคำนวณ modular exponentiation และการเลือกกุญแจเป็นคนละส่วนกับ protocol ที่ปลอดภัย การใช้ RSA จริงยังมีข้อกำหนดเรื่องการเข้ารหัสข้อมูลและ padding จึงไม่ควรนำตัวอย่าง textbook ไปใช้เข้ารหัสข้อความตรง ๆ

Hybrid Encryption

แนวคิดทั่วไปใช้ public-key mechanism ช่วยตั้งกุญแจหรือห่อกุญแจ แล้วใช้ symmetric encryption กับข้อมูลจำนวนมาก ช่วยรวมข้อดีด้านการจัดการกุญแจและประสิทธิภาพ ไม่ใช่ต้องเลือกระบบเดียวใช้ทุกส่วน

ลองตอบ: เข้ารหัสถึงผู้รับด้วยกุญแจสาธารณะของใคร

เฉลยและเหตุผล: ในแนว public-key encryption ใช้ public key ของผู้รับ และผู้รับใช้ private key ที่สัมพันธ์กันถอด ไม่ใช่ใช้ private key ของผู้ส่งเพื่อทำความลับ

ลองตอบ: Hash กับ encryption เหมือนกันหรือไม่

เฉลยและเหตุผล: ไม่ Hash ให้ digest ตามข้อมูลและออกแบบให้ย้อนหาต้นฉบับยาก ไม่ใช่ระบบถอดกลับด้วยกุญแจตามการใช้งานปกติ

จำให้ได้: แยก confidentiality, key exchange, encryption และ signature อย่าอธิบายทุกอย่างด้วยคำว่า “เข้ารหัส” คำเดียว

บล็อกข้อความ 17 — Use the shift cipher with key = 15 to encrypt the message “HELLO.”

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
Use the shift cipher with key = 15 to encrypt the message “HELLO.”
Solution
We encrypt one character at a time. Each character is shifted 15 characters down. Letter H is encrypted to W. Letter E is encrypted to T. The first L is encrypted to A. The second L is also encrypted to A. And O is encrypted to D. The cipher text is WTAAD.
Example 30.3

บล็อกข้อความ 18 — Use the shift cipher with key = 15 to decrypt the message “WTAAD.”

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
Use the shift cipher with key = 15 to decrypt the message “WTAAD.”
Solution
We decrypt one character at a time. Each character is shifted 15 characters up. Letter W is decrypted to H. Letter T is decrypted to E. The first A is decrypted to L. The second A is decrypted to L. And, finally, D is decrypted to O. The plaintext is HELLO.

อ่านข้อความต้นฉบับที่สกัดได้ (อังกฤษตามไฟล์)
Let us give a trivial example to make the procedure clear. Our example uses small numbers, but note that in a real situation, the numbers are very large. Assume g = 7 and 
 p = 23. The steps are as follows:
1. Alice chooses x = 3 and calculates R1 = 73 mod 23 = 21.
2. Bob chooses y = 6 and calculates R2 = 76 mod 23 = 4.
3. Alice sends the number 21 to Bob.
4. Bob sends the number 4 to Alice.
5. Alice calculates the symmetric key K = 43 mod 23 = 18.
6. Bob calculates the symmetric key K = 216 mod 23 = 18.
The value of K is the same for both Alice and Bob; 
gxy mod p = 718 mod 23 = 18.
