เปิดบทนี้ในเล่มรวม

อ่านบทนี้ให้เห็นภาพทั้งระบบ

Internet ในมุมส่วนประกอบคือ end systems, access networks, communication links และ packet switches เชื่อมเป็นเครือข่ายของเครือข่าย ในมุมบริการคือโครงสร้างที่ให้แอปบนปลายทางแลกข้อมูลผ่านบริการของ protocol stack

Network edge คือเครื่องปลายทางที่รันแอป ส่วน network core คือ router และลิงก์ที่ขนส่งข้อมูลระหว่างเครือข่าย Access network พาเครื่องเข้า router แรก เช่น DSL, cable, Ethernet หรือ wireless อย่าสับสน AP กับ ISP และอย่าคิดว่าทุกอุปกรณ์ตามทางต้องรันแอปเดียวกับผู้ส่ง

ส่วนสูตร/ลักษณะเพิ่มอะไรแล้วเปลี่ยน
Processing dprocตรวจ header/bit และตัดสินใจกำลังประมวลผลและงานที่ทำ
Queuing dqueueรอส่งใน bufferโหลดและรูปแบบ traffic
Transmission dtransL/Rขนาด packet L กับอัตราลิงก์ R

เวลารวมที่โหนดโดยพื้นฐาน dnodal=dproc+dqueue+dtrans+dprop เพิ่ม bandwidth ลด transmission แต่ไม่ได้ลด propagation ที่มาจากระยะ ยิ่ง packet ยาวใช้เวลาผลักลงสายมาก แต่สัญญาณบิตแรกไม่ได้เดินทางช้าลงเพราะ packet ยาว

ตัวอย่าง packet 1,500 bytes ลิงก์ 10 Mb/s ยาว 1,000 km ความเร็วสัญญาณ 2×10⁸ m/s: L=12,000 bits ได้ dtrans=1.2 ms; dprop=1,000,000/(2×10⁸)=5 ms; บิตสุดท้ายถึงปลายลิงก์หลังเริ่มส่งประมาณ 6.2 ms เมื่อไม่คิด delay อื่น

Queue และ Packet Loss

Traffic intensity ρ=La/R เมื่อ a เป็น packet/s และ L เป็น bit/packet หากเฉลี่ยเข้าใกล้ความสามารถส่งออก delay มักเพิ่มอย่างไม่เป็นเส้นตรง แต่ ρ เพียงตัวเดียวไม่บอก delay แน่นอน ต้องมีสมมติฐานการมาถึงและการจัดคิว Buffer เต็มทำให้ packet บางตัวถูกทิ้ง ไม่ใช่เพิ่ม delay ได้ไม่สิ้นสุดในหน่วยความจำจำกัด

Bandwidth-delay product เป็นจำนวนบิตที่ลิงก์หรือเส้นทางรองรับอยู่ระหว่างทางตามนิยาม delay ที่เลือก ถ้า R=100 Mb/s และ one-way propagation=10 ms มีบิตอยู่บนลิงก์ประมาณ 1,000,000 bits; ถ้าคิด window เพื่อรอ ACK ให้ใช้ RTT ตามบริบท

Throughput และคอขวด

เส้นทางหลายลิงก์ที่ไม่มี traffic อื่นมี throughput ยาวนานถูกจำกัดด้วยลิงก์ที่ช้าที่สุด เช่น 100,10,50 Mb/s ได้เพดาน 10 Mb/s ไม่ใช่ค่าเฉลี่ย 53.33 Mb/s หากมีหลาย flow แชร์ลิงก์ ต้องคิดการแบ่งและโหลดเพิ่ม

ตัวอย่าง server ส่งได้ Rs=20 Mb/s, client รับได้ Rc=5 Mb/s และลิงก์กลาง R=100 Mb/s แชร์เท่า ๆ กัน 50 การเชื่อมต่อ เพดานแต่ละการเชื่อมต่อในแบบจำลองคือ min(20,5,100/50)=2 Mb/s ไม่ใช่เห็น client 5 แล้วตอบ 5 ทันที

Circuit กับ Packet Switching แบบความน่าจะเป็น

หากลิงก์ 1 Mb/s ผู้ใช้แต่ละคนส่ง 100 kb/s เมื่อ active Circuit จองได้ 10 คน ส่วน packet switching ให้มีผู้ใช้ลงทะเบียนมากกว่านั้นได้ถ้าไม่ได้ active พร้อมกันทั้งหมด การคำนวณโอกาสเกินความจุใช้ binomial เมื่อแต่ละคน active อิสระตามสมมติฐาน ไม่ควรสรุปว่าได้ 35 คนเสมอโดยไม่มีโอกาส active และเกณฑ์ความเสี่ยง

ประวัติและความปลอดภัยในสไลด์

ยุค packet switching, ARPANET, TCP/IP และเว็บช่วยให้เข้าใจว่า Internet เติบโตโดยเชื่อมเครือข่ายต่างระบบ ตัวเลขที่เขียน “ปัจจุบัน” ในสไลด์หมายถึงเวลาของเอกสาร ส่วนภัย malware, DoS, sniffing และ spoofing ให้ทบทวนร่วมบท 31

ลองตอบ: เพิ่ม R จาก 10 เป็น 100 Mb/s ในตัวอย่าง 1,500 bytes เวลารวมเหลือเท่าไร

เฉลยและเหตุผล: dtrans เหลือ 0.12 ms แต่ dprop ยัง 5 ms จึงรวม 5.12 ms ไม่ได้ลดลง 10 เท่าทั้งหมด

ลองตอบ: ρ=0.5 บอก delay แน่นอนได้หรือไม่

เฉลยและเหตุผล: ไม่ ต้องรู้รูปแบบการมาถึง การกระจายขนาด packet และระบบคิว จึงใช้เป็นตัวชี้โหลด ไม่ใช่ delay สำเร็จรูป

จำให้ได้: ลิงก์เร็วลด L/R; ระยะกำหนด d/s; throughput ดูคอขวด; network core ไม่เท่ากับแอปปลายทาง

การสื่อสารข้อมูล (Data communications) คือการแลกเปลี่ยนข้อมูลระหว่างอุปกรณ์ผ่านสื่อส่งข้อมูล เช่น สายทองแดง ใยแก้วนำแสง หรือคลื่นวิทยุ คำว่า “ข้อมูล” หมายถึงสิ่งที่ต้องการสื่อ ส่วน “สัญญาณ” คือรูปทางกายภาพที่ใช้ขนข้อมูลนั้น ข้อความเดียวกันอาจส่งด้วยสัญญาณไฟฟ้าบนสาย หรือสัญญาณแสงบนไฟเบอร์ก็ได้

ระบบสื่อสารมี 5 องค์ประกอบ ได้แก่ Message ข้อมูลที่ส่ง, Sender ผู้ส่ง, Receiver ผู้รับ, Transmission medium สื่อกลาง และ Protocol กติกาที่ทั้งสองฝ่ายเข้าใจร่วมกัน การต่อสายติดเพียงอย่างเดียวยังไม่ทำให้สื่อสารได้ หากรูปแบบข้อความหรือขั้นตอนตอบรับไม่ตรงกัน

คุณภาพการสื่อสารพิจารณา Delivery ส่งถึงปลายทางที่ถูกต้อง, Accuracy ข้อมูลถูกต้อง, Timeliness ถึงทันเวลา และ Jitter ความแปรปรวนของเวลาหน่วง เสียงสนทนาอาจยอมเสียข้อมูลบางส่วนได้แต่ไวต่อความล่าช้า ต่างจากไฟล์ที่ต้องครบทุกบิต

เครือข่าย โทโพโลยี และการประเมินระบบ

Network คือกลุ่มอุปกรณ์หรือโหนดที่เชื่อมกันเพื่อแลกเปลี่ยนข้อมูลและใช้ทรัพยากรร่วมกัน เกณฑ์สำคัญคือ Performance สมรรถนะ, Reliability ความเชื่อถือได้ และ Security ความปลอดภัย เครือข่ายที่เร็วแต่ล่มบ่อยจึงไม่ใช่เครือข่ายที่ดีโดยอัตโนมัติ

Star ต่อแต่ละเครื่องเข้าศูนย์กลาง ดูแลง่ายและสายเสียมักกระทบเครื่องเดียว แต่ศูนย์กลางเสียกระทบมาก; Bus ใช้สายหลักร่วมกัน; Ring เชื่อมเป็นวง; Full mesh เชื่อมทุกคู่ มีจำนวนลิงก์ n(n−1)/2 ถ้ามี 5 โหนดต้องใช้ 10 ลิงก์และแต่ละโหนดมี 4 จุดเชื่อมต่อ

LAN เน้นบริเวณจำกัด เช่น อาคาร; WAN เชื่อมบริเวณห่างไกล; Internetwork คือการเชื่อมหลายเครือข่าย ส่วน Internet เป็นระบบเครือข่ายของเครือข่ายที่ใช้ชุดโปรโตคอลอินเทอร์เน็ตร่วมกัน Intranet คือเครือข่ายภายในองค์กร ไม่ได้หมายความว่าต้องตัดขาดจาก Internet เสมอ

เสริมติว: Protocol กับ Standard

Protocol กำหนด Syntax รูปแบบ, Semantics ความหมาย และ Timing ลำดับหรือจังหวะของการแลกเปลี่ยนข้อมูล ส่วน Standard คือข้อกำหนดที่ตกลงร่วมกันเพื่อให้ผู้ผลิตต่างรายทำงานร่วมกันได้ อย่าตอบว่า protocol คือ “โปรแกรม” เพราะกติกาเดียวกันอาจมีการพัฒนาโปรแกรมได้หลายแบบ

ลองตอบ: ถ้าเครื่อง 6 เครื่องต่อ full mesh ต้องใช้กี่ลิงก์

เฉลยและเหตุผล: 6×5/2 = 15 ลิงก์ แต่ละเครื่องต่อ 5 ลิงก์ หาร 2 เพราะลิงก์ A–B กับ B–A คือคู่เดียวกัน

ลองตอบ: ทำไมเปิดไฟล์ได้ครบแต่ประชุมเสียงกระตุก

เฉลยและเหตุผล: ไฟล์มักมีการส่งซ้ำเพื่อให้ครบ ส่วนเสียงไวต่อ delay และ jitter แม้ throughput เฉลี่ยพอ ความหน่วงแปรปรวนก็ทำให้เล่นเสียงไม่ต่อเนื่องได้

จำให้ได้: จำ 5 องค์ประกอบ / 4 คุณภาพ / 3 ทิศทาง / mesh = n(n−1)/2 และแยก Internet ออกจากเครือข่ายทั่วไป

คลื่นไซน์อธิบายด้วย Amplitude ขนาดสัญญาณ, Frequency จำนวนรอบต่อวินาที และ Phase ตำแหน่งเทียบเวลา Period คือเวลาต่อรอบ T=1/f หน่วยความถี่เป็น Hz และคาบเป็นวินาที ความยาวคลื่น λ=v/f ขึ้นกับความเร็วการแพร่ในสื่อ v

สัญญาณผสมประกอบด้วยหลายความถี่ Bandwidth ทางความถี่เป็นช่วง fสูง−fต่ำ หน่วย Hz ต่างจากคำว่า bandwidth ที่มักใช้เรียกอัตรารับส่งสูงสุดหน่วย bit/s ในการพูดเรื่องเครือข่าย ต้องอ่านหน่วยทุกครั้ง

Bit rate, baud และหน่วย

Bit rate คือจำนวนบิตต่อวินาที ส่วน Signal rate หรือ baud คือจำนวนสัญลักษณ์ต่อวินาที ถ้าหนึ่งสัญลักษณ์เลือกได้ M สถานะ จะบรรทุก log₂M บิตในแบบจำลองคงที่ จึงได้ Rb = Rs log₂M ตัวอย่าง 16 สถานะ = 4 บิต/สัญลักษณ์ ที่ 2,400 baud ได้ 9,600 bit/s ก่อนหัก overhead

1 byte = 8 bits ในโจทย์ที่ใช้ฐานสิบ 1 Mb/s = 10⁶ bit/s แต่ 1 MiB = 2²⁰ bytes อ่าน MB, Mb, MiB ให้ต่างกัน ไฟล์ 10 MB ส่งบนลิงก์ 10 Mb/s ใช้เวลาส่งอย่างน้อย 8 วินาทีในแบบอุดมคติ

ตัวอย่าง Nyquist และ Shannon

ช่องไร้ noise ตามแบบจำลอง Nyquist มี Rmax = 2B log₂M ถ้า B=3,000 Hz และ M=4 ได้ 12,000 bit/s เป็นขีดจำกัดตามสมมติฐาน ไม่ใช่รับประกันอุปกรณ์จริง

ช่องมี noise ตาม Shannon มี C=B log₂(1+S/N) โดย S/N ต้องเป็นอัตราส่วนเชิงเส้น ถ้า SNR=30 dB ต้องแปลงเป็น 10^(30/10)=1,000 เมื่อ B=3,000 Hz จะได้ C≈29,902 bit/s ไม่ใช่แทน 30 ลงไปโดยตรง

Nyquist ใช้พิจารณาจำนวนระดับและ bandwidth ในช่องอุดมคติ ส่วน Shannon เป็นขีดจำกัดข้อมูลจาก bandwidth กับ SNR ถ้าโจทย์ให้ทั้งคู่ต้องตรวจข้อจำกัดทั้งสอง ไม่เลือกค่ามากกว่าเพียงเพราะดูดีกว่า

ลองตอบ: สัญญาณ 2 kHz มีคาบเท่าไร

เฉลยและเหตุผล: T=1/2000 = 0.0005 วินาที = 0.5 ms

ลองตอบ: 64-QAM หนึ่งสัญลักษณ์แทนกี่บิต

เฉลยและเหตุผล: ไม่ โดยเฉพาะ queuing delay เปลี่ยนตามโหลดและการจัดตารางส่ง

จำให้ได้: แยกการตั้งสถานะ การเลือกเส้นทาง การจองทรัพยากร และวิธี store-and-forward ให้ได้

Hash, MAC และ Digital Signature

Hash สร้าง digest โดยไม่ใช้กุญแจลับในนิยามพื้นฐาน หากส่งข้อความกับ hash ผ่านช่องที่ผู้โจมตีแก้ได้ทั้งคู่ ผู้โจมตีอาจคำนวณ hash ใหม่ จึงยังไม่ยืนยันผู้ส่ง

Message Authentication Code ใช้กุญแจลับร่วมกันช่วยตรวจ integrity และยืนยันว่ามาจากผู้รู้กุญแจ ส่วน Digital Signature ใช้ private key เซ็นและ public key ตรวจตาม scheme ช่วยให้ตรวจหลักฐานโดยผู้ที่ไม่มีกุญแจเซ็นได้ ลายเซ็นไม่ทำให้เนื้อหาลับโดยอัตโนมัติ

คำว่า MAC ใน security หมายถึง Message Authentication Code ต่างจาก MAC address และ Medium Access Control ใน LAN ต้องดูบริบทก่อนแปล

กลับสารบัญ ↑

Replay, Nonce และ Certificate

Replay คือส่งข้อความเก่าที่ถูกต้องซ้ำเพื่อให้ระบบยอมรับอีกครั้ง แม้ข้อความมีการเข้ารหัสหรือ MAC ก็ยังต้องมี freshness เช่น nonce, timestamp หรือ sequence ตาม protocol ที่ตรวจอย่างถูกต้อง

Certificate ผูกตัวตน/ชื่อกับ public key ภายใต้ความเชื่อถือของผู้ออก การมี certificate ไม่ได้ทำให้ทุกข้อมูลในเว็บเป็นจริง ต้องตรวจชื่อ อายุการใช้งาน ความเชื่อถือ และการใช้ตามนโยบายของระบบด้วย

เสริมชุด Network: การป้องกันหลายระดับ

มาตรการกายภาพ เช่นห้องอุปกรณ์และไฟสำรอง, มาตรการปฏิบัติงาน เช่นบัญชีเฉพาะบุคคล การกำหนดสิทธิ์และสำรองข้อมูล, มาตรการเครือข่าย เช่นการแบ่งเครือข่ายและกรอง traffic สนับสนุนกัน การติด firewall อย่างเดียวไม่แทน patch, password policy หรือการติดตามเหตุการณ์

ตัวอย่างภัยในสไลด์ ได้แก่ malware, sniffing, spoofing และ DoS ต้องแยก sniffing ที่ดักสังเกตจาก spoofing ที่ปลอมแหล่ง และ DoS ที่กระทบการให้บริการ

ลองตอบ: เซ็นข้อความแล้วข้อความลับหรือไม่

เฉลยและเหตุผล: ไม่ ผู้ตรวจลายเซ็นอาจอ่านเนื้อหาได้ หากต้องการความลับต้องมี encryption ตามระบบเพิ่มด้วย

ลองตอบ: Password ถูกต้องแปลว่ามีสิทธิ์ทุกไฟล์หรือไม่

เฉลยและเหตุผล: ไม่ Authentication ผ่านแล้วต้องตรวจ authorization ของการกระทำนั้นต่อ

จำให้ได้: CIA, authentication/authorization, hash/MAC/signature และ freshness เป็นคนละหน้าที่

         จาเป็นต้องมี protocols สาหรับการถ่ายโอนข้อมูลที่เชื่อถือได้, หรือการควบคุมความแออัด

•     Q: จะทาให้ Packet Switching เป็นเหมือน Circuit Switching ได้อย่างไร?
        มีการประกันแบนด์วิดช์สาหรับ app ที่มีช้อมูลเสียงและวีดีโอ
        ยังคงเป็นปัญหาที่รอคนแก้ไขต่อไป (อ่านบทที่ 7)
